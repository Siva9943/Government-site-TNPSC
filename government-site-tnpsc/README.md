# Government Site TNPSC

## Overview
This project is a government website for the TNPSC (Tamil Nadu Public Service Commission). It serves as an informational platform for candidates, providing updates, announcements, and resources related to TNPSC exams and services.

## Project Structure
The project is organized as follows:

```
government-site-tnpsc
├── src
│   ├── index.html          # Main HTML document
│   ├── css
│   │   └── style.css      # Styles for the project
│   ├── js
│   │   ├── nav.js         # Navigation bar functionality
│   │   └── main.js        # Additional JavaScript functionality
│   └── components
│       └── nav.html       # Navigation bar HTML structure
├── package.json            # npm configuration file
├── .gitignore              # Git ignore file
└── README.md               # Project documentation
```

## Features
- Responsive navigation bar that adapts to different screen sizes.
- Vertical menu display on mobile devices, activated by a button click.
- Dynamic content updates for announcements and exam information.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd government-site-tnpsc
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open `src/index.html` in a web browser to view the project.

## Usage
- Click the menu button to toggle the visibility of the vertical navigation menu on mobile devices.
- Use the navigation links to access different sections of the site.
